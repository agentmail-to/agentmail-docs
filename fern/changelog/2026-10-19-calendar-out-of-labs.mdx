## Summary

Calendar is now available to every organization in US production, with no opt-in. Every inbox already has a calendar: your agents can create events, send and answer invitations, and react to start and end webhooks without joining AgentMail Labs first.

### What's new?

- **No opt-in:** Calendar is no longer in AgentMail Labs. The calendar API works for every organization in US production (`api.agentmail.to`).
- **Invitations fill the calendar:** calendar invitations emailed to any inbox are now added to its calendar, where before they were added only for organizations in Labs.
- **Console:** every organization in US production sees the Calendar view and the calendar API key permissions.
- **Availability:** Calendar is not yet available in EU production (`api.agentmail.eu`), which returns `403` with the message `Calendar isn't available in this region yet`.
- Agent Armor stays in AgentMail Labs.

<Note>
  Read the [Calendar overview](https://docs.agentmail.to/calendar) to get started.
</Note>
