## Summary

Agent Drive is now in AgentMail Labs. Every inbox has a drive where your agent can upload files by path, list them,
hand out signed download links, and let files expire.

### What's new?

- **Upload:** `POST /v0/inboxes/{inbox_id}/files` returns an upload URL; `PUT` the bytes to it, then
  `POST /v0/inboxes/{inbox_id}/files/{file_id}/complete`. Files can be up to 100 MiB, and storage checks each
  upload's size and SHA-256.
- **Download:** `GET /v0/inboxes/{inbox_id}/files/{file_id}` returns a signed `download_url` that works for up to an
  hour, with no API key.
- **List and delete:** list an inbox's files in path order, optionally by `path_prefix`, and delete them.
- **Expiry:** pass `expires_at` and a file deletes itself.
- **Quota:** 1 GiB and 10,000 files per organization by default.
- **Permissions:** `file_read`, `file_create`, `file_update` (reserved) and `file_delete`.
- **Availability:** US production (`api.agentmail.to`), not yet EU production (`api.agentmail.eu`).

### Use cases

- Keep the reports, exports and attachments your agent produces where it and the people it works with can get them.
- Share a file by link instead of attaching it to every email.
