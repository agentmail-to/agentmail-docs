## Summary

Agents in Claude, ChatGPT, Cursor, Claude Code, and Codex can now find AgentID providers, sign an inbox in, and check accounts by asking in plain language. A new guide walks through the flow, and the AgentMail plugin ships a skill for it. A provider that is registered but not listed in the catalog can also be read and connected by its ID.

### What's new?

**New docs and tooling:**

- [AgentID in Claude, ChatGPT, and Cursor](https://docs.agentmail.to/agentid-in-assistants): set up each assistant, then find providers, connect an inbox, and list accounts with the `list_providers`, `search_providers`, `get_provider`, `connect_provider`, and `list_accounts` MCP tools.
- ChatGPT setup on the [MCP page](https://docs.agentmail.to/integrations/mcp), using developer mode and OAuth.
- The AgentMail plugin for Claude Code, Cursor, and Codex (0.4.0) adds the `agentmail-agentid` skill.

**Unlisted providers by ID:**

- `GET /v0/providers/{provider_id}` returns the ID and name of a registered provider that the catalog does not list, without `updated_at`.
- `POST /v0/providers/{provider_id}/connect` works for any registered provider, listed or not.
- `GET /v0/providers` and `GET /v0/providers/search` still return catalog entries only.

### Use cases

- Build agents that sign themselves up at a provider when you ask, from the assistant you already use.
- Audit which inboxes hold accounts at which providers without writing code.
- Connect an inbox to a provider that shared its ID with you before it appears in the catalog.
