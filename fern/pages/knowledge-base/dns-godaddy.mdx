## Steps

1. Log in to your [GoDaddy account](https://www.godaddy.com)
2. Go to **My Products**, find your domain, and click **DNS**
3. Scroll down to the **DNS Records** section
4. Click **Add** to create each record AgentMail requires

## Adding the TXT records (SPF, DKIM, DMARC)

Add one TXT record for each row below:

| Record | Name | Value |
| --- | --- | --- |
| SPF | `mail` | The SPF value from AgentMail |
| DKIM | The DKIM selector host from AgentMail (e.g., `selector._domainkey`) | The DKIM value from AgentMail |
| DMARC | `_dmarc` | The DMARC value from AgentMail |

Set **Type** to `TXT` and **TTL** to `1 Hour` for each one.

<Warning>
GoDaddy automatically wraps TXT values in double quotes, so do **not** add your own quotes around the value. If you do, the record will end up double-quoted and fail validation.
</Warning>

<Warning>
GoDaddy automatically appends your domain to the Name field. Enter only the host portion. For example, enter `selector._domainkey`, not `selector._domainkey.yourdomain.com`.
</Warning>

<Note>
Do not add anything to an existing SPF record on your root domain (`@`). AgentMail's SPF record goes on the `mail` host, so your existing SPF for Google Workspace or another service stays exactly as it is.
</Note>

<Note>
Legacy orgs should keep existing working DNS records in place. For new domain setup, add the TXT selector records shown in AgentMail.
</Note>

## Adding the MX records (receiving and bounces)

Add one MX record for each row below:

| Record | Name | Value | Priority |
| --- | --- | --- | --- |
| Receiving | `@` | The receiving MX value from AgentMail | `10` |
| Bounces (MAIL FROM) | `mail` | The `feedback-smtp` MX value from AgentMail | `10` |

Set **TTL** to `1 Hour`. Skip the receiving MX if you created the domain as send-only (`inbound_enabled: false`). The `mail` MX must be the only MX record on the `mail` host.

If you registered a subdomain such as `agents.yourdomain.com` to avoid conflicts with your existing email provider, add the subdomain to every name: `agents`, `mail.agents`, `_dmarc.agents`, and `selector._domainkey.agents`.

## Verification

After adding all records, go back to the [AgentMail Console](https://console.agentmail.to) and click **Verify Domain**.

GoDaddy DNS typically propagates within **15 to 30 minutes**, but it can occasionally take longer. If verification does not succeed right away, wait and try again.

## Common GoDaddy Issues

- **Double-quoted TXT values:** GoDaddy adds quotes around TXT records automatically. If you paste a value that already includes quotes, the final record will be double-quoted and will fail. Paste the raw value without quotes.

- **Name field auto-appends domain:** GoDaddy appends your domain to the Name field. Enter only the host portion (e.g., `selector._domainkey`). If you enter the full hostname, it will be duplicated as `selector._domainkey.yourdomain.com.yourdomain.com`.

- **Existing SPF record on your root domain:** Leave it unchanged. Do not add `include:agentmail.to` or any other AgentMail value to it. If an earlier guide told you to add `include:agentmail.to`, remove that mechanism: `agentmail.to` publishes no SPF record, so the include causes an SPF permanent error.

- **DNS managed elsewhere:** If you have changed your nameservers away from GoDaddy (e.g., to Cloudflare or Route 53), records added in the GoDaddy DNS panel will have no effect. Add records at the provider that controls your nameservers instead.

- **Parked domain or forwarding:** If your domain is parked or has forwarding enabled, GoDaddy may override your MX records. Disable parking and forwarding before setting up email receiving.
