## Steps

1. Log in to your [Namecheap account](https://www.namecheap.com)
2. Go to **Domain List** → click **Manage** next to your domain
3. Select the **Advanced DNS** tab
4. Click **Add New Record** for each record AgentMail requires

<Note>
Make sure your domain is using **Namecheap BasicDNS** or **Namecheap PremiumDNS** as its nameserver. If you've pointed your nameservers to another provider (e.g., Cloudflare), you'll need to add records there instead.
</Note>

## Adding the TXT records (SPF, DKIM, DMARC)

Add one TXT record for each row below:

| Record | Host | Value |
| --- | --- | --- |
| SPF | `mail` | The SPF value from AgentMail |
| DKIM | The DKIM selector host from AgentMail (e.g., `selector._domainkey`) | The DKIM value from AgentMail |
| DMARC | `_dmarc` | The DMARC value from AgentMail |

Set **Type** to `TXT Record` and **TTL** to `Automatic` for each one.

<Warning>
**Namecheap automatically appends your domain to the Host field.** Enter only the host portion. For example, enter `selector._domainkey`, not `selector._domainkey.yourdomain.com`.
</Warning>

<Note>
Do not add anything to an existing SPF record on your root domain (`@`). AgentMail's SPF record goes on the `mail` host, so your existing SPF for Google Workspace or another service stays exactly as it is.
</Note>

<Note>
Legacy orgs should keep existing working DNS records in place. For new domain setup, add the TXT selector records shown in AgentMail.
</Note>

## Adding the MX records (receiving and bounces)

Add one MX record for each row below:

| Record | Host | Value | Priority |
| --- | --- | --- | --- |
| Receiving | `@` | The receiving MX value from AgentMail | `10` |
| Bounces (MAIL FROM) | `mail` | The `feedback-smtp` MX value from AgentMail | `10` |

Namecheap lists MX records in the **Mail Settings** section of the **Advanced DNS** tab. Set it to **Custom MX** to add them.

Set **TTL** to `Automatic`. Skip the receiving MX if you created the domain as send-only (`inbound_enabled: false`). The `mail` MX must be the only MX record on the `mail` host.

If you registered a subdomain such as `agents.yourdomain.com` to avoid conflicts with your existing email provider, add the subdomain to every host: `agents`, `mail.agents`, `_dmarc.agents`, and `selector._domainkey.agents`.

## Verification

After adding all records, go back to the [AgentMail Console](https://console.agentmail.to) and click **Verify Domain**.

Namecheap DNS typically propagates within **15 to 30 minutes**, but in some cases it can take up to a few hours. If verification doesn't succeed immediately, wait and try again.

## Common Namecheap Issues

- **Host field auto-appends domain:** Namecheap adds your domain automatically. If your DKIM selector is `selector._domainkey`, enter just that, not the full `selector._domainkey.yourdomain.com`. If you enter the full value, the actual record will end up as `selector._domainkey.yourdomain.com.yourdomain.com`.

- **Existing SPF record on your root domain:** Leave it unchanged. Do not add `include:agentmail.to` or any other AgentMail value to it. If an earlier guide told you to add `include:agentmail.to`, remove that mechanism: `agentmail.to` publishes no SPF record, so the include causes an SPF permanent error.

- **Switching Mail Settings to Custom MX:** If Mail Settings is currently **Gmail**, **Private Email**, or **Email Forwarding**, switching to **Custom MX** replaces the MX records Namecheap was managing for that option. Re-add any MX records your existing email provider needs before saving, or your current email stops arriving.

- **Wrong nameserver:** If your domain uses **Custom DNS** nameservers (e.g., pointing to Cloudflare or Route 53), records added in the Namecheap Advanced DNS panel will have no effect. Add your records at the provider that controls your nameservers instead.

- **Propagation delays:** Unlike some providers, Namecheap propagation can take 15 to 30 minutes. If verification fails, wait and retry before troubleshooting further.
