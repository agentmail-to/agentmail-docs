<Note>
  Calendar is in AgentMail Labs. An organization admin turns it on for the whole
  organization by joining Labs in the console under [Settings, then
  Labs](https://console.agentmail.to/dashboard/settings/labs), and an
  organization API key with no permissions restriction can join with [Join
  Labs](https://docs.agentmail.to/api-reference/organizations/join-labs). API
  keys see the change within five minutes. Labs is available in US production
  (`api.agentmail.to`), not yet in EU production (`api.agentmail.eu`).
  Organizations without calendar access receive a `403` with the message
  `Calendar access is not enabled for this organization`. Upgrade to the latest
  Python or TypeScript SDK to use the calendar methods.
</Note>
